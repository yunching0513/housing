# 家庭收支調查：原始 xls 下載

## 這裡是什麼

行政院主計總處「家庭收支調查」網站的原始 `.xls` 下載檔，以表號命名（例如
`135-146.xls`、`101.xls`），共 4 組、75 個檔、約 6.8 MB。

這跟上層 `08_家庭收支調查/` 根目錄那 1353 個檔是**同一個調查的不同格式**：
根目錄是已整理、具表名的版本（`家庭收支調查_<表名>_民國<年>年.csv/.ods/.odt`），
這裡是未整理的原始 xls。

| 資料夾 | 檔數 | 內容 |
|---|---:|---|
| `2021 家庭收支調查（縣市別可支配所得）` | 7 | 表號區間命名（`135-146`、`153-158`…） |
| `2024 家庭收支調查（縣市別可支配所得）` | 7 | 同上，另一年度 |
| `2025年家庭收支調查（縣市別可支配所得）` | 7 | 同上，另一年度 |
| `2025 家庭收支` | 54 | 單一表號命名（`45`、`49`、`101`…），另含 7 個 `.doc` |

## 兩件還沒確認的事

**一、年度對應沒有驗證。** 資料夾名稱用的是西元年，而 `08_` 根目錄用民國年。
按 `民國年 = 西元年 - 1911` 推算，2021／2024／2025 分別對應民國 110／113／114 年，
而根目錄這三個年度各有 42／41／101 個檔。但這個對應是**從資料夾名稱推論的**，
沒有讀檔驗證——家庭收支調查的某一年度通常在隔年才公布，所以資料夾名稱也可能
指的是下載年份而不是調查年度。因此這裡**保留原始資料夾名稱，沒有改名**。

**二、跟根目錄的內容重疊沒有驗證。** 逐位元比對確認 75 個檔與根目錄 1353 個檔
沒有任何一個完全相同（格式不同，本來就不會相同）。但內容層面是否重複、
也就是同一張統計表是否已經以 csv／ods 形式存在，需要讀取 xls 才能判斷。
這台機器上沒有可讀舊版 BIFF 格式的工具（`xlrd`、`pandas`、LibreOffice 皆無），
所以這一點**尚未查證**。

要查證的話，裝一個讀取工具後比對表標題即可：

```bash
pip install xlrd && python3 -c "import xlrd; print(xlrd.open_workbook('135-146.xls').sheet_by_index(0).row_values(0))"
```
